LNbitsBox **0.9.14** is out now.

If you already have LNbitsBox running, you can update directly from the LNbitsBox admin interface without reflashing your device. For a fresh install, download the latest SD image from the [v0.9.14 release on GitHub](https://github.com/lnbits/LNbitsBox/releases/tag/v0.9.14).

## Major changes

LNbitsBox `0.9.14` is a small maintenance release focused on keeping its bundled funding sources up to date.

**Phoenixd** has been upgraded to `0.8.0`.

**Spark SDK** has been updated to `0.8.2`.

**Arkade SDK** has been updated to `0.4.32`.

If you are already on `v0.9.13`, you should think of `v0.9.14` as a tidy maintenance release that keeps the bundled funding-source stack current.

## Diff summary against v0.9.13

At a high level, the `v0.9.13 -> v0.9.14` change includes:

- Phoenixd package version updated to `0.8.0`
- Arkade sidecar source pin updated
- Spark sidecar source pin updated

As always, thanks to everyone running LNbitsBox and helping test, package, and improve it.
